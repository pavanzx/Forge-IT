# Forge-IT Adventure UI v2

This frontend is a large modular reference-driven UI system. It uses a black/charcoal shell, white workstation panels, restrained red/orange/yellow/green/blue/purple semantics, and six animated companion characters.

## Run

```powershell
cd frontend
py -m http.server 5500
```

Open http://localhost:5500.

Backend API defaults to http://localhost:8080/api. The UI is local-first so it remains usable when the backend is offline.
