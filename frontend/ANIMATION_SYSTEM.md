# Character Animation System

Each companion has idle breathing, walking, talking, warning and celebration states. The director chooses page anchors and invokes a character when the user performs a related action.

- Guide: onboarding/navigation
- Bot: technical questions
- Analyst: idea analysis
- Alert: risky or blocked actions
- Spark: creative suggestions
- Scout: search/tool discovery

Animations intentionally remain lightweight and CSS-based so the app remains usable with reduced motion.
